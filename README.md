# Barbearia Estilo — Sistema Web de Agendamento (MVP)

> Solução web mobile-first para automação de agendamentos e gestão de serviços para barbearias, desenvolvida para solucionar gargalos no atendimento manual via WhatsApp.

---

## 🎯 Sobre o Projeto
Este MVP foi desenvolvido para atender às necessidades de barbeiros solo, permitindo que os clientes reservem os seus horários de forma autônoma e sem necessidade de cadastro burocrático ou senha, enquanto o proprietário gerencia a sua grade semanal e o catálogo de serviços por meio de uma Chave de Acesso Administrativa (*Admin Key*).

O projeto está alinhado ao **ODS 8 (Trabalho Decente e Crescimento Econômico - Meta 8.3)**, promovendo a modernização tecnológica e a eficiência operacional de microempreendimentos.
